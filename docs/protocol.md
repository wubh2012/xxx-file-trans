# 传输协议（冻结）

> 版本：1.0 · 冻结日期：2026-09-21 · 事实来源：[需求文档.md §3](../需求文档.md)
> 本文档是发送端与接收端实现的**唯一协议对齐基准**。术语见 [CONTEXT.md](../CONTEXT.md)；几何自举决策见 [ADR-0001](./adr/0001-角标编码几何自举.md)。
>
> **冻结规则**：本协议为冻结项，内容以需求文档 §3 为唯一事实来源。

## 1. 帧结构

一帧 = **208 bit 帧头 + 数据区**，按**行优先、字节内 MSB first** 填入 `COLS × ROWS` 方块网格。

- **黑块 = 1，白块 = 0**（注意：与直觉相反，两端写死，不得各自约定）。
- 约束：`(COLS × ROWS) mod 8 == 0`，保证数据区字节对齐；发送端推导几何参数时必须满足。
- 数据区有效字节数由帧头 `DATA_LEN` 指明，末帧可小于 `CHUNK_SIZE`；补位不计入 CRC。

## 2. 帧头（26 字节 = 208 bit，大端序，MSB first）

| 偏移 | 长度 | 字段 | 说明 |
|---:|---:|---|---|
| 0 | 2B | `SYNC = 0xF0A5` | 同步字，**不参与 CRC** |
| 2 | 1B | `VER = 0x01` | 协议版本 |
| 3 | 4B | `FILE_ID` | 原始文件内容 CRC32（纯内容派生，同内容文件 ID 不变，与文件名无关） |
| 7 | 3B | `FRAME_NO` | 帧号；`0xFFFFFF` = 元数据帧哨兵 |
| 10 | 3B | `TOTAL_FRAMES` | 数据帧总数（不含元数据帧） |
| 13 | 2B | `DATA_LEN` | 本帧有效数据字节数（末帧可小于 `CHUNK_SIZE`） |
| 15 | 2B | `CHUNK_SIZE` | 标准分片字节数 |
| 17 | 1B | `COLS` | 方块列数（≤ 255） |
| 18 | 1B | `ROWS` | 方块行数（≤ 255） |
| 19 | 1B | `GEO` | 高 4 bit = BIT（1–15），低 4 bit = PAD（0–15） |
| 20 | 2B | `FLAGS` | bit15 = gzip 压缩标志；其余保留，必须为 0 |
| 22 | 4B | `CRC32` | CRC-32/ISO-HDLC，覆盖偏移 2–21（帧头除同步字）+ 数据区有效字节，补位不计 |

**CRC 覆盖范围是冻结关键**：CRC 覆盖偏移 2–21 共 **20 字节**（帧头中除同步字与 `CRC32` 字段本身之外的全部字段）+ 数据区有效字节一并纳入计算。

## 3. CRC（冻结）

- 算法：**CRC-32/ISO-HDLC**，与 `zlib.crc32` 同参：
  宽度 32 · 多项式 `0x04C11DB7`（反射 `0xEDB88320`）· 初值 `0xFFFFFFFF` · 输入输出反射 · 异或输出 `0xFFFFFFFF`。
- **双端自检向量**：`CRC32(b"123456789") == 0xCBF43926`。两端启动时必须自检通过；pytest 中以独立位级实现与 `zlib.crc32` 交叉校验，防止参数漂移。
- 校验失败 → **坏帧整帧丢弃**，不污染文件。

## 4. 元数据帧（冻结）

- 帧号 `FRAME_NO = 0xFFFFFF`（哨兵值）；插入节奏：**每轮播放首帧 + 每 100 帧插入一次**。
- 数据区布局（**12 + nameLen 字节**，大端序）：

| 偏移 | 长度 | 字段 | 说明 |
|---:|---:|---|---|
| 0 | 1B | 压缩方式 | `0x01` = gzip |
| 1 | 4B | `plainSize` | 原始文件大小 |
| 5 | 4B | `compressedSize` | 压缩后大小 |
| 9 | 2B | `nameLen` | 文件名字节长 |
| 11 | 1B | 保留 | 必须为 0 |
| 12 | nameLen B | 文件名 | UTF-8 |

- `12 + nameLen` 超出本帧 `CHUNK_SIZE` 的元数据帧**整帧丢弃并告警**，不影响数据帧接收。
- 元数据帧是接收端确定落盘文件名与 `data.bin` 截断长度的**唯一来源**；元数据缺失时数据帧照常落盘但**不启动还原**。

## 5. 角标规则与几何自举（冻结）

- 角标 = **白色实心方块，边长严格等于 3×BIT 像素**，贴数据网格四角外沿。
- 接收端自举流程：局部自适应阈值 → 检测角标（四条几何一致性约束）→ 测角标白块边长 ÷ 3 得 BIT → 由四角标定出的画布尺寸得 COLS / ROWS → 透视校正 → 读帧头 → 与帧头 `GEO / COLS / ROWS` 交叉校验，不一致**整帧丢弃**。
- 全程**无默认参数**：接收端不内置任何几何默认值，一切从画面推导（依据见 ADR-0001）。

## 6. 参数锁定（冻结）

- 同一 `FILE_ID` 首帧落地时，接收端把 fileId、几何参数（COLS/ROWS/BIT/PAD）、chunkSize 写入 `meta.json` 并锁定。
- 此后帧头参数与锁定值不一致 → **整帧拒绝并告警**，旧进度不可续；须用户手动清空该任务目录后重收（**硬锁**，不自动作废进度）。

## 7. 自检向量

| 输入 | 期望 CRC-32/ISO-HDLC |
|---|---|
| `b"123456789"` | `0xCBF43926` |
