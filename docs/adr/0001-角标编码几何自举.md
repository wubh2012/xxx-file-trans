# 0001 - 采用角标编码法实现接收端几何自举

日期：2026-09-21 · 状态：已接受

## 背景

需求确定"接收端无默认几何参数，一切从画面自行解析"。这产生自举悖论：要读帧头里的几何参数（COLS/ROWS/BIT/PAD），必须先按几何参数采样网格；而采样前几何参数未知。

## 决策

角标尺寸与 BIT 建立严格比例关系：**角标白色实心方块边长 ≡ 3×BIT 像素**，贴数据网格四角外沿。接收端先检测角标（四条几何一致性约束），测白块边长 ÷ 3 得 BIT，由四角标定画布尺寸得 COLS/ROWS，再读帧头交叉校验，不一致整帧丢弃。

## 备选方案

1. **网格自检测**（被否）：沿扫描线找黑白跳变间距估计方块尺寸。实现复杂，摩尔纹与压缩伪影下跳变间距不可靠。
2. **引导帧**（被否）：第一帧固定用一套全局已知几何发送参数。两端仍各藏一套常量，违背"无默认参数"的需求；且引导帧几何本身无法校验。

## 后果

- 正面：全程无默认值、确定性推导、一次测量即锁定全部几何；帧头交叉校验提供第二道防线。
- 负面：角标比例成为协议冻结项，角标尺寸今后不可独立变更；角标测量精度直接决定 BIT 推导，测量误差 ±1 像素在 BIT 很小时影响放大，calibrate 需覆盖该场景。
